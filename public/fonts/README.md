# Feather Bold

The presentation uses Feather Bold for headings, the wordmark, step numerals,
floating display words and French vocabulary labels. Body copy uses Nunito.
The original TTF is served locally and preloaded so all slides share the same
display face, including French accents and the œ ligature.

Source file: [Feather Bold.ttf](https://github.com/NicoAAA/Productos-agr-colas/blob/dcfa2c4824e9e61663725326a84ae32cf59f78b9/assets/fonts/Feather%20Bold.ttf).
