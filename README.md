# Meet Camille

An animated Duolingo-inspired presentation built with React, Vite, and Motion.

All slide titles, installation labels, step numerals, floating display words and French clothing labels use locally served Feather Bold, matching the Duolingo heading references. Body copy stays in Nunito. The heading font is preloaded and includes French accents; its source and embedded license reference are recorded in [public/fonts/README.md](public/fonts/README.md).

The title and credits adapt to the available width without overlapping Duo; each member’s full name stays together when wrapping. A layered French Duo illustration keeps the baguette in his right wing and greets with a continuous, rounded free wing tucked under the torso. The speaker button beside fullscreen toggles all effects without advancing the slide and remembers the preference locally. Audio starts after a click, tap or keyboard gesture, in line with browser playback rules. Muting fades out current sounds and cancels scheduled notes; navigation removes sounds from the previous scene while character transitions can finish across page changes. Hiding the tab stops audio, and resizing or entering/exiting fullscreen does not replay cues. Original short tones, filtered noise, pitch bends and bell partials are generated locally with Web Audio in `src/audio/`, with a shared volume bus and compressor; no external audio downloads or libraries are needed. Browsers without Web Audio retain the complete silent presentation.

## Development

Requires Node.js 24 and npm.

```sh
npm ci
npm run dev
```

Open the address printed by Vite in your local browser. In a cloud workspace, forward port 5173.

## Validation and production build

```sh
npm run lint
npm run build
npm run preview
```

The production output is in `dist/`. Fonts and character artwork are served locally.

The previous standalone presentation is preserved in `docs/previous-presentation.html`; its original `camille.jpg` reference was not present in the repository.
